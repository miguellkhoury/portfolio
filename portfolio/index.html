03 — Projects

Things I've built

Four projects at different stages, from live deployments to active development. All built to solve real problems.

AutoLinker · dashboard preview

SaaS Platform · Maritime

AutoLinker

The maritime professional network — connecting seafarers, candidates, agencies, and academies through one platform built specifically for the industry.

  • 23-table PostgreSQL schema on Supabase with Row-Level Security, JWT auth, and real-time messaging
  • Four role-based dashboards: Candidate, Candidate Plus, Agency, Academy, each with isolated data views
  • CRI (Crew Reliability Index) scoring engine, certificate expiry tracking with automated alerts
  • AI-matching engine, vessel & fleet profiles, verification badge system
  • PWA support, security headers, B2B REST API and email notification edge functions

Fleet Operations Center · dashboard preview

Ops Dashboard · AutoLinker Extension

Fleet Operations Center

A single-file crew management console built for a live fleet pilot — real vessels, real crew data, zero placeholder rows. Built to answer one question fast: who needs relief, and who's ready to go.

  • Fleet dashboard across 12 vessels — crew count, relief-due/urgent counts, readiness % per ship
  • Ship view with crew grouped by department (Bridge / Deck / Engine / Galley), each position a clickable card
  • Slide-in crew detail panel: passport/medical/visa status, certs, CRI score, AI-recommended relief candidates
  • Gantt-style Fleet Timeline showing contract windows for flagged (yellow/red) positions
  • Smart filters by vessel, department, and crew status, plus a fleet-wide KPI readout

PawCode · dashboard preview

Consumer Product · Pet Tech

PawCode

Digital pet identity and QR recovery platform. Pets get a profile, a unique QR tag, and an owner who gets notified the moment someone scans it.

  • QR-triggered owner notification via Nodemailer — no app needed for the finder
  • Custom bone-shaped tag designer: 3 sizes, 3 materials, 12+ colours, front & back engraving
  • Lost pet mode, GPS scan location alerts, vaccination & medical records storage
  • Multi-pet accounts, scan history, tag reorder system, privacy controls
  • Full product site with interactive tag preview and pricing tiers
